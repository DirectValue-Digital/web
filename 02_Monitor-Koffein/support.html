Monitor-Koffein Support – We are here for you!

Welcome to the Monitor-Koffein support area. Do you have questions about preventing sleep on macOS, configuring startup settings, or sandboxing? Here you'll find answers to common questions.

1. How does Monitor-Koffein prevent sleep?

The App registers an assertion with macOS using the IOKit API (specifically kIOPMAssertionTypeNoDisplaySleep) to signal to the operating system that the display and system must stay active. Once you deactivate the timer or close the app, this assertion is clean released.

2. Does the app run quietly in the background?

Yes, Monitor-Koffein runs efficiently as a menu bar application in macOS. It does not display a dock icon or launch a heavy window interface, staying completely out of your way.

3. How does the Autostart feature work?

We use the modern macOS ServiceManagement framework (via SMAppService.mainApp) to register the app as a login item. This avoids old helper application setups and aligns with modern macOS security policies.

4. Is my privacy protected?

Absolutely. The App is fully sandboxed (ENABLE_APP_SANDBOX = YES), runs 100% offline, collects no data, contains no trackers, and never makes a network request. All configurations are stored locally on your Mac.

Monitor-Koffein Support – Wir sind für Sie da!

Willkommen im Support-Bereich von Monitor-Koffein. Haben Sie Fragen zum Verhindern des Ruhezustands, zum automatischen Start oder zur Datensicherheit? Hier finden Sie die Antworten auf die häufigsten Fragen.

1. Wie verhindert Monitor-Koffein den Ruhezustand des Mac?

Die App registriert eine Anforderung (Assertion) bei macOS über die IOKit-API (speziell kIOPMAssertionTypeNoDisplaySleep), um dem Betriebssystem zu signalisieren, dass der Monitor aktiv bleiben muss. Sobald die App deaktiviert oder geschlossen wird, wird diese Assertion sauber freigegeben.

2. Läuft die App unbemerkt im Hintergrund?

Ja, Monitor-Koffein läuft äußerst ressourcenschonend als reines Symbol in der macOS-Menüleiste. Es gibt kein störendes Dock-Icon und kein großes Programmfenster, das Ihre Arbeit unterbricht.

3. Wie funktioniert der automatische Start (Autostart)?

Wir nutzen das moderne macOS ServiceManagement-Framework (über SMAppService.mainApp), um die App als Anmeldeobjekt zu registrieren. Das vermeidet veraltete Hilfs-Apps und entspricht den modernen macOS-Sicherheitsrichtlinien.

4. Sind meine Daten in der App sicher?

Absolut. Die App läuft vollständig isoliert in der App Sandbox (ENABLE_APP_SANDBOX = YES), arbeitet 100 % offline, erfasst keine Daten, enthält keine Werbe-Tracker und baut niemals Netzwerkverbindungen auf.
